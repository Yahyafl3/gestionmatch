🔧 DÉPANNAGE:

Problème: Les logos ne s'affichent pas
Solution:
  1. Vérifier que les fichiers existent
  2. Vérifier la base de données:
     mysql -u root -proot gestion_match
     SELECT nom, image_path FROM equipes;
  3. Recompiler: mvn clean compile

Problème: Erreur de téléchargement
Solution:
  1. Vérifier la connexion Internet
  2. Télécharger manuellement depuis:
     https://flagcdn.com/w320/ma.png (Maroc)
     https://flagcdn.com/w320/br.png (Brésil)
     etc.

Problème: Erreur MySQL
Solution:
  1. Vérifier que MySQL est démarré
  2. Vérifier les identifiants (root/root)
  3. Vérifier que la base gestion_match existe
